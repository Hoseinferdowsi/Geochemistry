# 🌍 Geochemistry Analysis Web Application

یک برنامه وب برای تحلیل داده‌های زمین‌شیمی با قابلیت پردازش داده‌های سانسور شده، تشخیص مقادیر خارج از رده و تحلیل توزیع نرمال.

## 📋 ویژگی‌ها

### 🔧 پردازش داده‌های سانسور شده (Censored Data)
- پردازش مقادیر با علامت‌های `<` و `>` 
- تبدیل خودکار به مقادیر عددی
- ضریب‌های قابل تنظیم (0.75 برای `<` و 1.33 برای `>`)

### ⚠️ تشخیص مقادیر خارج از رده (Outliers)
- **روش IQR**: تشخیص بر اساس فاصله بین چارکی
- **روش Z-Score**: تشخیص بر اساس امتیاز استاندارد
- **روش Dorfel**: تشخیص بازگشتی با ضریب‌های آماری

### 📊 تحلیل توزیع نرمال
- محاسبه آمار توصیفی (میانگین، انحراف معیار، چولگی، کشیدگی)
- آزمون نرمال بودن (Shapiro-Wilk)
- گزارش‌گیری جامع

## 📖 راهنمای استفاده

### 1. آپلود فایل
- فایل Excel خود را در قسمت آپلود قرار دهید
- فرمت‌های پشتیبانی شده: `.xlsx` و `.xls`
- حداکثر حجم فایل: 32 مگابایت

### 2. انتخاب شیت
- پس از آپلود، شیت مورد نظر را انتخاب کنید
- تمام شیت‌های موجود در فایل نمایش داده می‌شود

### 3. انتخاب نوع تحلیل

#### پردازش داده‌های سانسور شده
- برای پردازش مقادیر مثل `<0.5` یا `>100`
- نتایج در فایل جدید ذخیره می‌شود

#### تشخیص مقادیر خارج از رده
- **IQR**: مناسب برای داده‌های با توزیع غیرنرمال
- **Z-Score**: مناسب برای داده‌های با توزیع نرمال
- **Dorfel**: روش پیشرفته با ضریب‌های آماری

#### تحلیل توزیع نرمال
- بررسی نرمال بودن داده‌ها
- محاسبه آمار توصیفی
- تولید گزارش‌های جامع

### 4. دانلود نتایج
- فایل‌های پردازش شده قابل دانلود هستند
- امکان دانلود همه فایل‌ها به صورت ZIP

## 🔧 تنظیمات

### تغییر پورت
در فایل `geochemistry_analysis_app.py`:
```python

```

### تغییر حداکثر حجم فایل
```python
app.config['MAX_CONTENT_LENGTH'] = 32 * 1024 * 1024  # 32MB
```

```python
left_coe = 0.75   # ضریب برای مقادیر <
```


## 🐛 عیب‌یابی

```bash

```

### خطای "Permission denied"
