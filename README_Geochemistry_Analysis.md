# Geochemistry Analysis — نسخه 3.1

وب‌اپلیکیشن Flask برای تحلیل داده‌های اکتشافی ژئوشیمیایی. کاربر فایل اکسل را آپلود می‌کند و پایپ‌لاین پردازش — از پاک‌سازی داده سانسورشده تا تحلیل چندمتغیره — را به‌صورت مرحله‌به‌مرحله با خروجی اکسل چندشیته اجرا می‌کند.

## امکانات (ترتیب تب‌ها)

| # | تب | توضیح |
|---|-----|--------|
| 1 | **آپلود** | آپلود فایل Excel، انتخاب شیت، انتخاب ستون‌های مختصات X/Y توسط کاربر (از تحلیل‌ها مستثنی می‌شوند) |
| 2 | **پردازش داده‌های سنسورد** | تبدیل مقادیر `<x` و `>x` با ضرایب تعدیل قابل تنظیم |
| 3 | **Outliers** | تشخیص مقادیر خارج از رده (IQR، Z-Score، Dörfel) |
| 4 | **جداسازی آنومالی‌ها** | طبقه‌بندی زمینه/آنومالی با ۲ تا ۱۰ کلاس قابل انتخاب و حدود دلخواه (کلاسیک، جعبه‌ای، فرکتالی) |
| 5 | **آمار توصیفی** | آمار کامل هر ستون عددی |
| 6 | **رسم نمودار** | نقشه پراکندگی مکانی با درون‌یابی IDW و انتخاب عنصر/عناصر |
| 7 | **توزیع نرمال** | روش‌های تبدیل قابل انتخاب (Box-Cox، Yeo-Johnson، Quantile، Rank، Log، Sqrt) با خروجی «بهترین روش» یا «همه روش‌ها» + شیت گزارش چولگی/کشیدگی/شاپیرو |
| 8 | **بررسی چندمتغیره** | ماتریس همبستگی (Pearson/Spearman/Kendall)، PCA، خوشه‌بندی سلسله‌مراتبی، K-Means |

## ساختار پروژه

```
geochemistry_analysis_app.py          # روت‌های Flask (≈28 روت)
processing_services.py                # منطق پردازش همه مراحل پایپ‌لاین
outliers.py                           # توابع تشخیص outlier
templates/geochemistry_analysis.html  # رابط کاربری تک‌صفحه‌ای (همه تب‌ها)
sessions/<session_id>/                # داده و خروجی هر جلسه کاری (state + فایل‌های اکسل)
uploads/  output/                     # پوشه‌های کمکی
backup/                               # اسکریپت‌های قدیمی/منسوخ (اجرا نشوند)
Geo-chemistry-Project-Brain/          # نقشه راه، طرح‌ها، سند ممیزی پروژه
```

## نصب و اجرا

```bash
pip install -r requirements.txt
python run_geochemistry_app.py
```

سرور روی **http://localhost:5001** راه‌اندازی می‌شود (پورت 5000 در ویندوز اغلب رزرو شده است).

## متغیرهای محیطی (اختیاری)

| متغیر | پیش‌فرض | توضیح |
|-------|---------|--------|
| `SECRET_KEY` | تصادفی در هر اجرا | کلید session فلش؛ در محیط production حتماً تنظیم شود |
| `FLASK_DEBUG` | `0` | با مقدار `1` حالت debug فعال می‌شود (فقط محیط توسعه) |
| `SESSION_TTL_DAYS` | `7` | جلسات و آپلودهای قدیمی‌تر از این تعداد روز، خودکار حذف می‌شوند |

## API (خلاصه)

| متد | مسیر | کاربرد |
|-----|------|--------|
| POST | `/upload` | آپلود فایل و ساخت جلسه |
| POST | `/get_columns` | ستون‌های یک شیت |
| POST | `/save_coordinates` | ذخیره ستون‌های X/Y |
| POST | `/process_censored_data` | پردازش سانسور |
| POST | `/process_outliers` | تشخیص مقادیر خارج از رده |
| POST | `/process_anomaly_separation` | جداسازی آنومالی (چندکلاسه) |
| POST | `/process_statistics` | آمار توصیفی |
| POST | `/process_plots` | رسم نقشه‌ها |
| POST | `/process_normalization` | تبدیل توزیع نرمال |
| POST | `/process_correlation`, `/process_pca`, `/process_hierarchical_clustering`, `/process_kmeans` | تحلیل چندمتغیره |
| GET | `/session/<id>/status` | وضعیت جلسه |
| GET | `/download/<id>/<filename>` | دانلود خروجی (با محافظت path traversal) |
| GET | `/download_all/<id>` | دانلود همه خروجی‌ها به‌صورت ZIP |

## نکات امنیتی

- روت‌های دانلود با `realpath` داخل پوشه جلسه محصور شده‌اند (رفع path traversal).
- `secret_key` از متغیر محیطی خوانده می‌شود؛ `debug` پیش‌فرض `False` است.
- پاک‌سازی خودکار جلسات قدیمی هر ۶ ساعت اجرا می‌شود.
