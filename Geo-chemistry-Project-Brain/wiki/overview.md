# 🧭 نمای کلی پروژه

## هدف
سامانه‌ای برای **پردازش و تحلیل داده‌های ژئوشیمی** که داده‌های آنالیز شیمیایی نمونه‌ها را (معمولاً Excel) می‌گیرد و با اجرای مراحل استاندارد — پردازش داده‌های سانسور شده، حذف/اصلاح Outlier ها، تبدیل به توزیع نرمال و رسم نقشه‌های توزیع عناصر — خروجی‌های آمادهٔ استفاده برای زمین‌شناسان تولید می‌کند.

## تاریخچه
- پروژه از نسخه‌های ابتدایی اسکریپت‌محور (CLI) شروع شده و به تدریج به وباپ Flask تبدیل شده است.
- اسکریپت‌های مستقل اولیه (`Censored_Data.py` ،`outliers.py` ،`normalization_process.py` ،`Draw_Plot.py`) بعداً در `processing_services.py` دوباره‌پیاده‌سازی شدند — بنابراین **اسکریپت‌های مستقل عمدتاً تکراری‌اند** (به `roadmap.md` R1/R2 مراجعه شود).
- پوشهٔ پروژه v3.1 نام دارد ولی README هنوز نسخهٔ 2.6 را نشان می‌دهد ⚠️

## امکانات کلیدی
1. **پردازش داده‌های سانسور شده:** تبدیل `<0.5` / `>100` با ضرایب قابل تنظیم
2. **تشخیص Outlier:** روش‌های IQR ،Z-Score و Dorfel (بازگشتی)
3. **تبدیل به توزیع نرمال:** Box-Cox ،Yeo-Johnson ،Quantile ،Rank-Based ،Log ،Sqrt + آزمون Shapiro-Wilk
4. **نقشهٔ توزیع عناصر:** درون‌یابی IDW / Linear / Cubic / Nearest + نمودار همبستگی
5. **تحلیل نمونه‌های تکراری:** محاسبهٔ RPD و دسته‌بندی کیفیت عناصر
