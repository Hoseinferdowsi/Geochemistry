تحلیل فایل app.py

1. ساختار کلی برنامه:
   - برنامه یک وب اپلیکیشن Flask است
   - از کتابخانه‌های زیر استفاده می‌کند:
     * Flask برای ساخت وب اپلیکیشن
     * werkzeug برای مدیریت فایل‌ها
     * datetime برای مدیریت زمان
     * subprocess برای اجرای اسکریپت‌های خارجی
     * json برای پردازش داده‌های JSON

2. تنظیمات اولیه:
   - پوشه آپلود فایل‌ها: 'uploads'
   - حداکثر حجم فایل: 16 مگابایت
   - فرمت‌های مجاز فایل: xlsx و xls

3. تحلیل توابع:

   a. تابع allowed_file(filename):
      - بررسی مجاز بودن فرمت فایل
      - ورودی: نام فایل
      - خروجی: True/False
      - بررسی پسوند فایل در لیست فرمت‌های مجاز

   b. تابع index():
      - مسیر اصلی برنامه (/)
      - نمایش صفحه اصلی (dashboard)
      - استفاده از template 'dashboard/index.html'

   c. تابع sample_file():
      - مسیر: /sample_file
      - دانلود فایل نمونه ورودی
      - نام فایل خروجی: 'نمونه_فایل_ورودی.xlsx'
      - مدیریت خطا با try/except

   d. تابع guide():
      - مسیر: /guide
      - نمایش صفحه راهنما
      - استفاده از template 'dashboard/guide.html'

   e. تابع upload_file():
      - مسیر: /upload
      - متد: POST
      - عملکردها:
        * بررسی وجود فایل در درخواست
        * بررسی نام فایل
        * بررسی فرمت مجاز
        * ذخیره فایل با نام منحصر به فرد
        * ایجاد پوشه خروجی
        * اجرای اسکریپت read_duplicates.py
        * پردازش نتایج و آماده‌سازی پاسخ
      - مدیریت خطاهای مختلف
      - پاکسازی فایل‌های موقت

   f. تابع serve_result(filename):
      - مسیر: /results/<filename>
      - ارسال فایل نتایج به کاربر
      - بررسی وجود فایل
      - مدیریت خطاها

   g. تابع download_plots(results_dir):
      - مسیر: /download_plots/<results_dir>
      - ایجاد فایل ZIP از نمودارها
      - شامل نمودارهای:
        * پراکندگی (scatter_plots)
        * مقایسه (comparison_plots)
        * Thompson-Howarth (log_thompson_howarth_plots)
        * نمودارهای خلاصه
      - مدیریت حافظه با BytesIO
      - مدیریت خطاها

4. نکات امنیتی:
   - استفاده از secure_filename برای نام فایل
   - محدودیت حجم فایل
   - محدودیت فرمت فایل
   - پاکسازی فایل‌های آپلود شده پس از پردازش

5. نکات فنی:
   - استفاده از محیط مجزا برای اجرای اسکریپت
   - تنظیم encoding به utf-8
   - مدیریت حافظه با استفاده از BytesIO برای فایل‌های ZIP
   - ساختار پوشه‌های خروجی منظم

6. پیشنهادات بهبود:
   - اضافه کردن لاگ‌گیری پیشرفته
   - اضافه کردن سیستم احراز هویت
   - اضافه کردن محدودیت تعداد درخواست‌ها
   - بهبود مدیریت خطاها با پیام‌های دقیق‌تر
   - اضافه کردن تست‌های واحد
   - اضافه کردن مستندات API
