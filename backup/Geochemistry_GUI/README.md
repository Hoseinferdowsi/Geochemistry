# 🖥️ Geochemistry GUI — رابط دسکتاپی (بایگانی‌شده)

این پوشه شامل **رابط دسکتاپی PyQt5** پروژهٔ ژئوشیمی است که از پروژهٔ اصلی جدا و در اینجا بایگانی شده است.

## فایل‌ها
- `gui_app.py` — رابط دسکتاپی تحلیل نمونه‌های تکراری (محاسبه RPD و دسته‌بندی کیفیت عناصر)
- `requirements.txt` — وابستگی‌های این رابط (PyQt5 و کتابخانه‌های پایه)

## وضعیت
- ⚠️ **ارجاع خراب:** `gui_app.py` اسکریپت `read_duplicates.py` را فراخوانی می‌کند که **وجود ندارد**.
- برای کارکرد، باید به اسکریپت `read_duplicate_parallel.py` از پروژهٔ اصلی وصل شود (همان CLI با آرگومان‌های `--input` و `--output` را می‌پذیرد و `results.json` تولید می‌کند).
- فایل نمونهٔ ورودی (`static/files/sample_input.xlsx`) در پروژهٔ اصلی نگه داشته شده است (وباپ هم از آن استفاده می‌کند).

## اجرا
```bash
pip install -r requirements.txt
python gui_app.py
```
